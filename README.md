# Enclosure Monitoring Dissertation Project
## Overview
This repository contains all code developed for the design and implementation of a low-cost IoT based predictive environmental monitoring system for wildlife conservation enclosures.

## Repo Contents
- TakeSensorReadings.ino: Sketch for the ESP32-S3 to read BME280 sensor data and publish to Mosquitto via MQTT
- EnclosureMonitor.ipynb: Jupyter Notebook containing the full ARIMA training pipeline
- predict.py: Python deployment script that generates predictions and writes them to InfluxDB
- arima_temperature.pkl (Generated by running the notebook): Trained ARIMA model for temperature 
- arima_humidity.pkl (Generated by running the notebook): Trained ARIMA model for Humidity
- temp_scaler.pkl (Generated by running the notebook): Min-Max scaler for temperature
- humid_scaler.pkl (Generated by running the notebook): Min-Max scaler for humidity

## Generating model files
all .pkl files are generated by running the EnclosureMonitor.ipynb file.

## Credentials
The TakeSensorReadings.ino file contains placeholder values for sensitive credentials such as SSID, password, and mqtt_server.
These must be replaced with your own credentials before uploading.
